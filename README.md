# Ôn thi OOP (C#)

Web tĩnh ôn thi môn Lập trình hướng đối tượng bằng C#: lý thuyết ngắn gọn, code mẫu từ bài giảng, flashcard và trắc nghiệm có giải thích.

- `index.html`: trang chủ, hiện điểm cao nhất từng chương
- `chuong1.html` đến `chuong4.html`: C# cơ bản; lớp, constructor, static, generic; kế thừa, đa hình, interface; SOLID và design pattern
- Có nút chuyển chế độ sáng/tối (nhớ lựa chọn, mặc định theo hệ thống)
- Trắc nghiệm xáo ngẫu nhiên cả câu hỏi lẫn đáp án mỗi lần làm

Mở trực tiếp `index.html` trong trình duyệt hoặc bật GitHub Pages cho repo.
